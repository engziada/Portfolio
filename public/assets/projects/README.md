# Project Images

This directory should contain images for your projects:

1. Place screenshots or images representing your projects here
2. Name them according to the project they represent (e.g., `nokia-flow-one.jpg`, `vc4-inventory.jpg`, etc.)
3. You can create subdirectories for projects with multiple images

Recommended image sizes:
- Project thumbnails: 800x600 pixels (4:3 ratio)
- Project details: 1200x800 pixels
- Project logos: 200x200 pixels (1:1 ratio)
